# Fundeka — Materials, Assets & Marketing Repository

This repository contains **all non-code materials** for the Fundeka project — including design assets, branding, screenshots, marketing content, 3D files, and reference material.

It acts as the **single source of truth** for anything visual, promotional, or illustrative used across:
- The Fundeka mobile app
- Marketing campaigns
- Social media content
- Presentations, demos, and pitch material

---

## 📁 What Lives in This Repo

### 🎨 Design & Branding
- Logos, mascots, icons, SVGs
- Style guides and brand references
- Color palettes and typography references

### 📸 Screenshots & Covers
- App screenshots (for stores, docs, and marketing)
- Cover images and promo visuals

### 🎥 Video & Motion
- Marketing video scripts
- Motion design assets
- Blender files for animations (logo, cards, etc.)

### 🧠 References & Ideation
- Design references
- Inspiration files
- Notes and exploratory assets (PureRef, moodboards, etc.)

### 🧱 3D Assets
- Blender project files
- Models, scenes, and animation drafts

---

## 🧭 Repo Philosophy

- **No app source code** lives here  
- Files are organized by *purpose*, not file type alone  
- Raw / editable files (e.g. `.blend`, `.svg`) are kept alongside or clearly separated from exported assets  
- This repo should be safe to share with designers, marketers, and collaborators  

---

## 🛠️ Suggested Workflow

1. **Design / Create**
   - Work in Blender, Figma, Inkscape, etc.
   - Save editable files in `/3D`, `/design`, or `/branding`

2. **Export**
   - Export final PNG/SVG/MP4 files into `/exports` or relevant marketing folders

3. **Use**
   - App pulls assets from the main Fundeka code repo
   - Marketing pulls from `/marketing`

4. **Archive**
   - Old or unused concepts move to `/archive`

---

## 📌 Naming Conventions

- Use `kebab-case` for filenames  
- Include purpose when relevant:
  - `logo-animation-v1.blend`
  - `flashcards-marketing-deck.svg`
  - `app-home-dark.png`
